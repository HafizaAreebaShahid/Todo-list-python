# Todo-list-python

A to do list created with python. The items in this to do list save to a text file and stays when the program is closed.

## Status

Still in development Features are being added step by step.

## Current features

1. Read tasks from a text file.
2.  Write tasks to a text file.

## Planned features

1. View tasks
2. Add task
3. Remove task with validation
4. Main menu.

## Concepts Used

1. Functions
2.  File Handling
3.  Lists.

## How to run
python main.py
